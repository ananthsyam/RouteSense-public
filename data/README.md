# RouteSense: Data README

This repository includes a small, reproducible demo dataset and documents where to obtain the full, authorized dataset. The demo is *synthetic* and exists solely to demonstrate the schema, loader, validation and the Streamlit application. It is not the full production dataset.

## Acquisition (full dataset)

The project is built around the [Brazilian E-Commerce Public Dataset by Olist](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce). Olist is licensed under **CC BY-NC-SA 4.0**; use only in compliance with that license. Attribution and the original source must be retained if redistributing. 

To reproduce the full dataset:
1. Download the Olist CSVs from Kaggle.
2. Place raw files under `data/raw/` (do not commit).
3. Reproduce cleaned/enriched outputs using `notebooks/01_prepare_data.ipynb` (sanitized in this repo), or your own pipeline.
4. The synthetic sources (`data/synthetic/`) are already committed and provide the documented targets for delivery attempts.

## Load the demo

```sql
CREATE DATABASE IF NOT EXISTS delivery_db CHARACTER SET utf8mb4;
USE delivery_db;
source sql/schema.sql;  -- non-destructive
source sql/insert.sql;  -- loads data/demo/*.csv (local_infile required)
```

Or regenerate the demo:
```bash
python scripts/build_demo_dataset.py --orders 300
```

## Validate

```bash
python scripts/validate_data.py           # check demo
python scripts/validate_data.py --source-targets  # check committed synthetic sources vs targets
python -m pytest tests/test_data_integrity.py -v
```
